Build a full-stack subscription web app named Khurpi for selling microgreens.

**PRODUCT REQUIREMENTS (Consolidated & Updated):**
- **Stack:** Frontend (React), Backend (FastAPI), Database (MongoDB).
- **Core Features:**
    - **Product Catalog:** Customers can browse microgreens.
    - **Single Purchase:** Users can buy single products via a cart and checkout.
    - **Subscriptions:** Customers can create/manage subscriptions (items, quantity, frequency, delivery days). All subscription plans are monthly.
    - **User Profile & Address Management:** Manage profile and multiple delivery addresses (Address Label, Line 1, 2, City, PIN, Area/Sector, Landmark). Lat/Lng is saved internally but not visible to the user. Map location is mandatory.

    - Dashboard with CRUD for products, users, subscriptions.

    - **Coupons & Referrals:** Full CRUD for managing discount coupons and referrals.
- **Customer-Facing Features:**
    - **Unified Discount Code:** A single input on the checkout page for both coupon and referral codes.
    - **Referral Program:** Customers can generate their own unique referral code from their profile.
    - **Dynamic Delivery Days:** During subscription creation, users must select a number of delivery days that matches their chosen plan (e.g., select 2 days for Twice a Week).
- **UI/UX:**
    - Clean, premium, mobile-first responsive design.
    - A unified Header and Footer on all pages.
